## 📚 今日完成内容

### 核心论文1: VLA机制性研究 (ICLR Workshop)
**论文**: *Not All Features Are Created Equal: A Mechanistic Study of VLA Models*  
**arXiv**: 2603.19233

#### 关键发现
| 发现 | 细节 |
|-----|------|
| **视觉主导** | 视觉通路而非语言通路主导动作生成 |
| **跨任务注入** | 99.8%的episode与源任务轨迹对齐，暴露空间绑定的运动程序 |
| **语言作用** | 取决于任务结构：唯一视觉指定时语言被忽略；多目标共享时语言必需 |
| **架构分工** | Expert pathway编码运动程序，VLM pathway编码目标语义 |
| **工具发布** | Action Atlas交互式探索平台 |

#### 对VLA设计的启示
- 视觉编码器质量至关重要
- 简单任务可能不需要复杂语言理解
- Expert pathway应独立于VLM优化

### 核心论文2: 因果世界模型 (LingBot-VA)
**论文**: *Causal World Modeling for Robot Control*  
**arXiv**: 2601.21998 | **代码开源**: ✅

#### 三大核心设计
1. **共享潜在空间 + MoT架构**: 视觉和动作token统一表示，Mixture-of-Transformers处理
2. **闭环Rollout**: 使用真实观测而非预测观测，避免误差累积
3. **异步推理流水线**: 动作预测与执行并行，支持实时控制

#### 性能表现
- 长程操作: 显著优势
- 数据效率: Post-training阶段高效
- 泛化性: 对新配置强泛化
