# RSSM (Recurrent State-Space Model) 详细介绍报告

## 摘要

RSSM (Recurrent State-Space Model，循环状态空间模型) 是由 Danijar Hafner 等人在 DeepMind 提出的世界模型架构，是 Dreamer 系列算法的核心组件。本报告详细介绍 RSSM 的原理、架构、演进及应用。

---

## 一、背景与动机

### 1.1 世界模型的挑战

在基于模型的强化学习 (Model-Based RL) 中，世界模型需要解决以下挑战：

| 挑战 | 说明 |
|------|------|
| **部分可观测性** | 智能体无法直接获取环境的完整状态 |
| **不确定性建模** | 环境动态具有随机性 |
| **长程预测** | 需要准确预测多步未来 |
| **高效学习** | 从有限数据中学习 |

### 1.2 RSSM 的核心思想

> **RSSM 结合了确定性循环 (RNN) 和随机隐变量 (VAE) 的优点，既能够记住长期历史，又能够建模环境的不确定性。**

### 2.2 核心组件

#### 2.2.1 确定性路径 (Deterministic Path)

```python
# 确定性状态更新 (RNN)
h_t = f_θ(h_{t-1}, z_{t-1}, a_{t-1})

其中:
- h_t: 时刻 t 的确定性隐状态
- z_{t-1}: 上一时刻的随机隐状态
- a_{t-1}: 上一时刻的动作
- f_θ: GRU/LSTM 循环网络
```

**作用**：
- 记住长期历史信息
- 提供稳定的时序依赖
- 防止梯度消失

#### 2.2.2 随机性路径 (Stochastic Path)

```python
# 后验分布 (有观测)
z_t ~ q_φ(z_t | h_t, x_t)

# 先验分布 (无观测，预测)
ẑ_t ~ p_θ(ẑ_t | h_t)

其中:
- z_t: 后验随机状态 (基于观测)
- ẑ_t: 先验随机状态 (预测)
- x_t: 当前观测
```

**作用**：
- 建模环境不确定性
- 捕捉观测中的随机信息
- 支持多模态预测

#### 2.2.3 信息融合

```python
# 融合状态
s_t = [h_t, z_t]  # 拼接或组合

# 用于:
- 重建观测: x̂_t = d_θ(s_t)
- 预测奖励: r̂_t = r_θ(s_t)
- 预测终止: ĉ_t = c_θ(s_t)
- 策略输入: a_t ~ π_φ(a_t | s_t)
```

### 2.3 训练目标

RSSM 的训练包含多个损失函数：

```
总损失 L = L_recon + L_kl + L_reward + L_value

1. 重建损失 (Reconstruction):
   L_recon = -E[log p_θ(x_t | s_t)]
   
2. KL 散度 (Regularization):
   L_kl = KL(q_φ(z_t | h_t, x_t) || p_θ(ẑ_t | h_t))
   
3. 奖励预测:
   L_reward = (r_t - r̂_t)²
   
4. 价值预测:
   L_value = (V_t - V̂_t)²
```

## 三、RSSM 的演进

### 3.1 版本演进时间线

```
2019: PlaNet (RSSM 首次提出)
    │
    ├── 连续随机状态 (Gaussian)
    ├── 在线规划 (CEM)
    └── 图像预测
    │
    ↓
2020: DreamerV1
    │
    ├── 引入 Actor-Critic
    ├── 想象训练 (Imagination)
    └── 行为学习
    │
    ↓
2021: DreamerV2
    │
    ├── 离散随机状态 (Categorical)
    ├── KL 平衡 (KL Balancing)
    └── Atari 离散动作
    │
    ↓
2023: DreamerV3
    │
    ├── 归一化技术
    ├── 任务自适应
    └── 150+ 任务通用
    │
    ↓
2025: DreamerV4 / R2-Dreamer
    │
    ├── Transformer 替代 RNN
    └── 无解码器变体
```

### 3.2 各版本关键改进

| 版本 | 随机状态 | 关键改进 |
|------|----------|----------|
| **PlaNet** | 连续 (Gaussian) | 基础 RSSM 架构 |
| **DreamerV1** | 连续 | Actor-Critic + 想象训练 |
| **DreamerV2** | 离散 (Categorical) | KL 平衡，Atari 支持 |
| **DreamerV3** | 离散 | 归一化，跨任务通用 |
| **DreamerV4** | 离散 | Transformer 架构 |

### 3.3 离散 vs 连续随机状态

| 特性 | 连续 (Gaussian) | 离散 (Categorical) |
|------|-----------------|-------------------|
| **表示能力** | 平滑变化 | 多模态分布 |
| **训练稳定性** | 一般 | 更好 |
| **KL 散度计算** | 解析解 | 采样估计 |
| **适用场景** | 连续控制 | 离散/连续均可 |

## 四、RSSM 的关键技术

### 4.1 KL 平衡 (KL Balancing)

DreamerV2 引入的重要技术：

```python
# 标准 KL 散度
KL(q || p) = E_q[log q(z) - log p(z)]

# KL 平衡 (解决后验坍塌)
KL_balance = α * KL(q || stop_gradient(p)) + 
             (1-α) * KL(stop_gradient(q) || p)

其中 α = 0.8 (典型值)
```

**作用**：
- 防止后验分布坍塌到先验
- 平衡信息压缩与重建质量
- 提升训练稳定性

### 4.2 自由比特 (Free Bits)

```python
# 带下界的 KL 损失
L_kl = max(KL(q || p), λ_free_bits)

典型值: λ_free_bits = 1.0 (每维)
```

**作用**：
- 保证随机状态保留最小信息量
- 防止模型完全忽略随机路径

### 4.3 DreamerV3 的归一化技术

| 技术 | 说明 |
|------|------|
| **Symlog 预测** | 压缩大值范围，稳定训练 |
| **Percentile 归一化** | 自适应奖励缩放 |
| **Layer Normalization** | 跨任务稳定 |
| **EMA 更新** | 稳定目标网络 |

## 五、RSSM 的应用

### 5.1 在 Dreamer 中的应用

```
Dreamer 训练流程:

1. 环境交互收集数据
   (s_t, a_t, r_t, s_{t+1})
   
2. 训练 RSSM 世界模型
   - 重建观测
   - 预测奖励
   - 学习状态表示
   
3. 想象训练 (Imagination)
   - 从当前状态展开想象轨迹
   - 在 latent 空间训练策略
   
4. 策略执行
   - 使用训练好的策略
   - 继续收集数据
```

### 5.2 衍生工作

| 工作 | 改进点 |
|------|--------|
| **R2-Dreamer** | 移除解码器，使用 Barlow Twins |
| **MuDreamer** | 无重建，纯预测目标 |
| **TransDreamer** | Transformer 替代 RNN |
| **DreamerV4** | Shortcut Forcing + Transformer |
| **DreamerNav** | 导航任务应用 |
| **DayDreamer** | 真实机器人应用 |

### 5.3 机器人应用

**DayDreamer (UC Berkeley)**：
- 将 RSSM 应用于真实机器人
- 四足机器人快速学习行走
- 机械臂操作任务

**关键优势**：
- 样本效率高
- 安全想象训练
- 迁移到真实环境

## 六、RSSM 的数学原理

### 6.1 状态空间模型

```
状态转移:
s_t ~ p(s_t | s_{t-1}, a_{t-1})

观测生成:
x_t ~ p(x_t | s_t)

其中 RSSM 将状态分解:
s_t = [h_t, z_t]

确定性转移:
h_t = f(h_{t-1}, z_{t-1}, a_{t-1})

随机转移:
z_t ~ p(z_t | h_t)  (先验)
z_t ~ q(z_t | h_t, x_t)  (后验)
```

### 6.2 变分推断

```
目标: 最大化证据下界 (ELBO)

log p(x_{1:T}) ≥ ELBO = 
    E_q[log p(x_{1:T} | z_{1:T}, h_{1:T})] 
    - KL(q(z_{1:T} | x_{1:T}) || p(z_{1:T}))

分解为每步:
ELBO = Σ_t [E[log p(x_t | s_t)] - KL(q(z_t) || p(ẑ_t))]
```

### 6.3 想象训练中的梯度传播

```
想象轨迹:
ŝ_{t+1} ~ p_θ(ŝ_{t+1} | ŝ_t, a_t)
â_t ~ π_φ(a_t | ŝ_t)

价值梯度:
∇_φ E[Σ γ^t r_t] ≈ ∇_φ V(ŝ_t)

通过世界模型反向传播:
∇_φ V = ∂V/∂ŝ * ∂ŝ/∂a * ∂a/∂φ
```

## 七、RSSM 的优势与局限

### 7.1 核心优势

| 优势 | 说明 |
|------|------|
| **分离确定性与随机性** | RNN 记住历史，VAE 处理不确定性 |
| **紧凑表示** | 低维 latent 空间高效规划 |
| **端到端学习** | 从像素直接学习 |
| **想象训练** | 安全高效的策略优化 |
| **长程预测** | 准确预测多步未来 |

### 7.2 局限性

| 局限 | 说明 | 改进方向 |
|------|------|----------|
| **RNN 瓶颈** | 长期依赖建模能力有限 | Transformer 替代 |
| **重建依赖** | 依赖像素重建学习 | 无解码器变体 |
| **计算成本** | 序列训练难以并行 | 并行化技术 |
| **离散状态** | 信息可能丢失 | 混合架构 |

## 八、实现细节

### 8.1 网络结构

```python
# 典型 RSSM 配置 (DreamerV3)

Encoder (CNN):
- 4层 Conv2d
- 通道: [32, 64, 128, 256]
- 输出: 32维特征

RSSM Core:
- 确定性状态 h: 200-1000 维 (GRU)
- 随机状态 z: 32-1024 维 (Categorical)
- 类别数: 32-64

Decoder (CNN):
- 4层 ConvTranspose2d
- 通道: [128, 64, 32, 3]

预测头:
- 奖励: MLP (200 → 1)
- 价值: MLP (200 → 1)
- 终止: MLP (200 → 1)
```

### 8.2 超参数

| 参数 | 典型值 | 说明 |
|------|--------|------|
| Batch Size | 16-64 | 序列批次 |
| Sequence Length | 50-64 | 训练序列长度 |
| Learning Rate | 1e-4 - 1e-3 | Adam |
| KL Scale | 0.1-1.0 | KL 损失权重 |
| Discount γ | 0.99 | 回报折扣 |
| Imagination Horizon | 15-50 | 想象步长 |

## 九、总结

### 9.1 核心贡献

RSSM 是模型强化学习的里程碑架构：

1. **统一了 RNN 和 VAE**：确定性 + 随机性
2. **支持想象训练**：在 latent 空间安全学习
3. **端到端可学习**：从像素到策略
4. **高度可扩展**：DreamerV3 覆盖 150+ 任务

### 9.2 与相关模型的对比

| 模型 | 架构 | 特点 |
|------|------|------|
| **RSSM** | RNN + VAE | 平衡效率与能力 |
| **Transformer** | Attention | 长程依赖更好 |
| **S4/Mamba** | State Space | 并行化训练 |
| **Diffusion** | 扩散模型 | 高质量生成 |

### 9.3 未来方向

- **Transformer 化**：如 DreamerV4
- **无解码器**：如 R2-Dreamer
- **多模态融合**：力觉、触觉等
- **物理先验**：结合物理引擎
