# 机器人数据采集方法与技术路线全面报告

## 摘要

机器人数据采集是具身智能（Embodied AI）的核心瓶颈之一。本报告系统梳理了当前主流的机器人数据采集方法、技术路线、平台工具及发展趋势，为研究者和从业者提供全面的技术参考。

## 二、遥操作数据采集（Teleoperation）

### 2.1 VR/AR 遥操作

#### 主流方案
| 设备 | 追踪方式 | 适用场景 | 成本 |
|------|----------|----------|------|
| **Apple Vision Pro** | 手部+眼动追踪 | 高精度灵巧操作 | ~3万元 |
| **Meta Quest 3** | 手部追踪 | 通用遥操作 | ~3000元 |
| **PICO 4 Ultra** | 手部追踪 | 企业级应用 | ~4000元 |
| **HTC Vive Pro** | 手柄+追踪器 | 工业级应用 | ~1万元 |

#### 代表性系统

**Open-TeleVision (MIT)**
- 跨平台Web系统（Vision Pro/Quest/iPad）
- 主动视觉反馈，沉浸式体验
- 支持双手灵巧操作数据采集

**Bunny-VisionPro**
- 实时双手灵巧遥操作
- 低延迟（<100ms）
- 适用于长程模仿学习任务

**Unitree XR Teleop**
- 宇树人形机器人配套
- 支持Vision Pro/Quest/PICO
- 全身控制+手部追踪

**LeVR Framework**
- 模块化VR遥操作框架
- 与LeRobot深度集成
- 支持Meta Quest手部追踪

### 2.2 同构遥操作（Kinesthetic Teaching）

#### 技术原理
```
操作者直接手持/穿戴机器人关节
         ↓
记录关节角度、力矩、速度
         ↓
映射为机器人动作轨迹
```

#### 主流平台
| 平台 | 特点 | 应用 |
|------|------|------|
| **ALOHA/Mobile ALOHA** | 双手臂同构遥操作 | 桌面/移动操作 |
| **HACTS** | 运动学等效控制 | 高精度示教 |
| **Mecha外骨骼** | EgoZero智能眼镜+触觉手套 | 高保真数据采集 |
| **北大-灵初外骨骼** | 灵巧手同构控制 | 物流分拣场景 |

**北大-灵初方案详情**：
- 同构型外骨骼灵巧手
- 单套设备日采集量：5000条
- 累计收集：超百万条手部操作数据
- 应用场景：柔性物体抓取、精密装配

### 2.3 手柄/控制器遥操作

| 设备 | 优势 | 局限 |
|------|------|------|
| **SpaceMouse** | 6DoF精密控制 | 学习曲线陡峭 |
| **Xbox/PS手柄** | 低成本、普及高 | 自由度有限 |
| **VR手柄** | 直觉操作 | 长时间疲劳 |
| **定制化手柄** | 任务专用 | 开发成本高 |

## 四、视频学习数据采集（Video Learning）

### 4.1 人类视频转示范

**Human-as-Sensor范式**：
- 采集人类操作视频（第三视角/第一视角）
- 通过视觉算法提取动作轨迹
- 映射到机器人动作空间

**技术挑战**：
- 人机形态差异（Morphology Gap）
- 视角变化处理
- 动作对齐精度

### 4.2 生成式数据合成

| 方法 | 技术 | 代表工作 |
|------|------|----------|
| **仿真到真实** | Domain Randomization | NVIDIA Isaac Sim |
| **视频生成** | Diffusion Models | Sora, GAIA-1 |
| **动作重定向** | Retargeting Networks | RH20T |
| **数据增强** | RL-based Augmentation | DiffusionRL |

**DiffusionRL**：
- 用RL技术丰富现有数据集
- 通过"升级"有限数据集获得更高成功率
- 无需额外数据采集工作

## 七、数据格式与标准

### 7.1 LeRobot Dataset Format (v3.0)

```python
{
    "codebase_version": "v3.0",
    "robot_type": "aloha",
    "total_episodes": 85,
    "total_frames": 127500,
    "fps": 50,
    "features": {
        "observation.images.cam_high": {
            "dtype": "video",
            "shape": [480, 640, 3],
            "video.fps": 50.0
        },
        "observation.state": {
            "dtype": "float32",
            "shape": [14]  # 关节状态
        },
        "action": {
            "dtype": "float32",
            "shape": [14]  # 动作指令
        }
    }
}
```

### 7.2 标准化趋势

- **CR-3-0602TS:2025**：《人形机器人数据采集训练场技术规范》
- **跨本体多样性**：支持不同机器人类型的统一格式
- **流式加载**：支持大规模数据集在线处理

| 方法 | 设备成本 | 人力成本 | 数据质量 | 单条成本估算 |
|------|----------|----------|----------|--------------|

## 九、发展趋势与挑战

### 9.1 发展趋势

| 趋势 | 描述 | 代表技术 |
|------|------|----------|
| **多模态融合** | 视觉+力觉+触觉+音频 | RH20T |
| **Human-as-Sensor** | 直接采集人类本体感知 | Mecha, 北大-灵初 |
| **生成式数据** | 用生成模型合成训练数据 | Sora, GAIA-1 |
| **云端协同** | 分布式数据采集与共享 | RoboTurk, LeRobot Hub |
| **实时学习** | 边采集边训练边部署 | π*₀.6 RECAP |

### 9.2 核心挑战

1. **数据稀缺性**：真实机器人数据收集成本高昂
2. **分布偏移**：训练数据与部署环境差异
3. **技能迁移**：跨任务、跨机器人的泛化
4. **安全约束**：自主采集中的安全保证
5. **标注质量**：长程任务的成功判定

## 十一、总结

机器人数据采集正处于快速发展期，从早期昂贵的同构遥操作，到VR/AR普及带来的低成本方案，再到生成式AI推动的合成数据，技术路线日趋多元。

**关键洞察**：
1. **没有银弹**：不同场景需要不同采集策略
2. **数据质量 > 数量**：高精度示教胜过大量噪声数据
3. **人在回路是关键**：人类专家知识仍不可替代
4. **仿真+真实结合**：降低成本的必由之路

**未来展望**：
- 世界模型将显著降低真实数据需求
- 遥操作硬件将更加轻便、低成本
- 跨机器人数据共享将加速技能积累
- 生成式数据将弥补真实数据稀缺
